# Raise Me Up: Infinite Ascent (beta)

An anime tower RPG where your heroes remember, answer back and fight on their own. Free early beta for Android.

## [Download the APK](https://github.com/sommi991/raise-me-up-beta/releases/latest/download/raise-me-up.apk)

If that link does not start a download, open the [releases page](https://github.com/sommi991/raise-me-up-beta/releases/latest) and tap `raise-me-up.apk`.

## Install
1. Tap the download link. If the browser warns the file may be harmful, choose **Download anyway**.
2. Open the file. When Android asks, allow your browser or Files app to install apps, then tap **Install**.
3. If Play Protect warns, tap **More details**, then **Install anyway**. On Samsung phones, if the install is blocked, turn off **Auto Blocker** (Settings, Security and privacy).
4. Open the game and turn your phone sideways. Enter a name and reveal your first heroes.

To update, install the newer APK over the old one. If Android says "App not installed", uninstall the old version first (progress is lost).

## Needs
Android 8 or newer, a 64-bit phone, about 300 MB free. Built and tested on a Samsung Galaxy S23.

## Voice
Heroes speak with your phone's text-to-speech (Settings, General management, Language, Text-to-speech output). To talk to a hero, tap **Speak**, then the microphone on your keyboard.
